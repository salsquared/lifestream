WHY THIS IS HERE, and why it must not become a URL again:

  `<Text>` from drei with no `font` prop silently resolves a face from
  cdn.jsdelivr.net at render time. This application is loopback-bound, single-user
  and local-only by design — so without this file every node label in the 3D views
  is BLANK offline, with no error. The same reasoning vendored the border geometry
  in client/public/topojson/.

  Sora is already the heading face of the project's HTML docs, so the 3D views and
  the written docs read as one system.

To re-vendor: fetch the URL above, confirm the checksum changes only if you intend
it to, and update this file.
